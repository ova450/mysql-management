# MySQL Management Scripts

Набор PowerShell-скриптов для управления локальным сервером MySQL 8.0/9.x на Windows.

## Состав

| Файл                        | Назначение                                             |
| :-------------------------- | :----------------------------------------------------- |
| `mysql-0-common.ps1`        | Общие переменные и функции                             |
| `mysql-1-start.ps1`         | Главный скрипт. Проверяет установку и запускает сервер |
| `mysql-2-restart.ps1`       | Запуск сервера (остановленного)                        |
| `mysql-3-mysql-console.ps1` | Подключение к консоли MySQL                            |
| `mysql-4-stop-options.ps1`  | Меню выхода: добавление в PATH, остановка сервера      |
| `mysql-5-stop.ps1`          | Остановка сервера                                      |

## Быстрый старт

powershell

```
# Из любой директории (после добавления в PATH)
mysql-1-start

# Или из папки со скриптами
.\mysql-1-start.ps1
```



## Что делают скрипты

### `mysql-1-start.ps1` — точка входа

- Переходит в папку скрипта
- Загружает `mysql-0-common.ps1`
- Вызывает `TestMySqlInstall`

### `mysql-0-common.ps1` — конфигурация

**Переменные:**

| Переменная      | Значение по умолчанию                         |
| :-------------- | :-------------------------------------------- |
| `ServiceName`   | MySql95                                       |
| `MySqlBin`      | `C:\Program Files\MySql\MySql Server 9.5\bin` |
| `DefaultDrive`  | D:                                            |
| `DefaultPath`   | `\.mysql-data`                                |
| `DataDir`       | D:.mysql-data                                 |
| `MySqlPort`     | 3306                                          |
| `MySqlUser`     | root                                          |
| `MySqlPassword` | 12345678                                      |

**Функции:**

- `TestMySqlRunning` — проверяет, слушает ли порт 3306
- `TestMySqlInstall` — проверяет установку сервера (по Service)
- `Get-MySqlPid` — возвращает PID процесса на порту
- `ConnectMySql` — выполняет SQL-запросы (опционально с паролем)
- `Progress` — выводит индикатор ожидания с точками

### `mysql-2-restart.ps1` — запуск сервера

- Удаляет проблемные файлы `undo_*` (баг MySQL 9.x на Windows)
- Запускает `mysqld.exe` скрыто с флагом `--console`
- Ждёт до 50 секунд (5 циклов по 10 секунд)
- При успехе — переходит к консоли
- При ошибке — выводит диагностику

### `mysql-3-mysql-console.ps1` — консоль

- Запускает `mysql.exe -u root -p`
- После выхода вызывает `mysql-4-stop-options.ps1`

### `mysql-4-stop-options.ps1` — меню выхода

- Предлагает добавить папку скриптов в PATH (если ещё не добавлена)
- Спрашивает, останавливать ли сервер

### `mysql-5-stop.ps1` — остановка

- Убивает все процессы `mysqld`
- Проверяет, что порт освободился
- Ждёт нажатия Enter перед закрытием

## Настройка под себя

1. Отредактируй переменные в `mysql-0-common.ps1`:

   - `$MySqlBin` — путь к bin MySQL
   - `$DataDir` — путь к папке с данными
   - `$MySqlPassword` — пароль root (если нужен)

2. Если сервер не запускается — проверь вручную:

   powershell

   ```
   & "$MySqlBin\mysqld.exe" --console --datadir="$DataDir"
   ```

   

## Известные особенности

### Баг MySQL 9.x на Windows

Сервер не запускается, если в `datadir` есть файлы `undo_001`, `undo_002`. Скрипт удаляет их перед каждым запуском. Это безопасно — файлы пересоздаются заново.

### Пароль root

По умолчанию скрипт использует пустой пароль (нажатие Enter). Если пароль установлен — измени `$MySqlPassword` в common.

### PATH

Скрипты работают без добавления в PATH (через `.\script.ps1`). При первом выходе из консоли скрипт предложит добавить папку в PATH для запуска из любой директории.

## Зависимости

- Windows 10/11
- PowerShell 5.1 или 7.x
- MySQL Server 8.0/9.x (установленный)
- Порт 3306 должен быть свободен

## Диагностика проблем

Если сервер не запускается — в скрипте `mysql-2-restart.ps1` есть диагностический блок. Он покажет:

- параметры запуска
- код завершения процесса
- последние строки из лога ошибок (`*.err` в папке DataDir)
